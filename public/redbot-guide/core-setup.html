Core Setup

Set prefix, roles, modlog, and load useful built-in cogs.

Prefix used

oa help

Modlog channel

Choose a text channel for moderation logs, copy its channel ID, then replace MODLOG_TEXT_CHANNEL_ID.

oa modlogset modlog MODLOG_TEXT_CHANNEL_ID

Load useful core cogs

oa load admin mod modlog mutes warnings cleanup filter permissions reports general economy trivia downloader customcom audio image streams

Useful server settings

oa set usebuttons True
oa helpset usemenus buttons
oa set deletedelay 10
oa set colour 0x5865F2
oa set serverfuzzy
