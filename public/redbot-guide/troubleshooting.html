Troubleshooting

Common errors hit during the setup and the fix.

Ticket button creates nothing

Check logs. In this setup, wrong welcome placeholders caused errors. Use {owner_mention}, not {ticket_owner.mention}.

oa settickets welcomemessage main Hey {owner_mention}! You've opened a ticket. <@977490076953116684> will be with you shortly.
Ticket logs posting in panel channel

Move logs to the real log channel.

oa settickets logschannel main 1139558361143193731
Button says “secondary Open a Ticket”

The style must be a number.

oa settickets clearmessage MESSAGE_ID
oa settickets addbutton MESSAGE_ID main 🎫 2 Open a Ticket
Welcome says 2th

The cog does not auto-format ordinals. Use “soul number {count}”.

YALC voice logs not showing

Run full setup, then set the channel for voice_state_update.

oa yalc setup CONFIRM
oa yalc setchannel voice_state_update 1504622317144117278
Dashboard dependency issues

Keep Dashboard in a separate venv and install flask-wtf==1.2.1.

python3 -m venv ~/redbotdashboard
source ~/redbotdashboard/bin/activate
pip install git+https://github.com/AAA3A-AAA3A/Red-Web-Dashboard.git
pip install flask-wtf==1.2.1
