Voice Logs

Final working setup: YALC routes voice state logs to 1504622317144117278. ExtendedModLog is the fallback.

Final preferred command: oa yalc setchannel voice_state_update 1504622317144117278

Option A: YALC full logging

oa repo add taakoscogs https://github.com/TaakoOfficial/TaakosCogs
oa cog install taakoscogs YALC
oa load YALC
oa yalc setup CONFIRM
oa yalc setchannel voice_state_update 1504622317144117278

Option B: ExtendedModLog fallback

oa cog install trusty-cogs extendedmodlog
oa load extendedmodlog
oa modlogset modlog 1139558361143193731
oa modlog channel 1504622317144117278 voice_change
oa modlog toggle true voice_change
oa modlog embeds true voice_change

Expected output

Voice join

@user has joined MOOD

Voice leave

@user has left MOOD
