Tickets

Support tickets with a bot-authored panel, GIF embed, logs channel, and auto-delete.

Replace placeholders like TICKET_CATEGORY_ID, LOG_TEXT_CHANNEL_ID, and BOT_PANEL_MESSAGE_ID with your own Discord IDs.
oa cog install aaa3a-cogs tickets
oa load tickets
oa settickets enabled main True
oa settickets supportroles main Curator
oa settickets categoryopen main TICKET_CATEGORY_ID
oa settickets logschannel main LOG_TEXT_CHANNEL_ID
oa settickets resetsetting main pingroles
oa settickets transcripts main True
oa settickets channelname main ticket-{id}
oa settickets autodeleteonclose main 0

Welcome message

oa settickets welcomemessage main Hey {owner_mention}! You've opened a ticket. SUPPORT_STAFF_MENTION will be with you shortly. Don't die waiting.

Panel button

First send the panel embed as the bot, then copy that bot message ID.

oa embed blue "🎫 Support Tickets" "Click the button below to open a support ticket! Our team will assist you as soon as possible."
oa settickets addbutton BOT_PANEL_MESSAGE_ID main 🎫 2 Open a Ticket
