FreeGames

Free game announcement cog setup with GamerPowerAPI, plus the upstream fix for the old fgset showsettings crash.

Status: the crash was accepted and fixed upstream. The developer changed the store collections to lists before sending them into cf.humanize_list(). Update the cog instead of manually patching it.

Install

Use the repo that provides freegames. Replace CRAY_BOUNTY_REPO_URL with the actual cray-bounty-cogs repository URL you use.

oa repo add cray-bounty-cogs CRAY_BOUNTY_REPO_URL
oa cog install cray-bounty-cogs freegames
oa load freegames

GamerPowerAPI setup

Replace #free-games with your own free games announcement text channel.

oa fgset gpapi channel #free-games
oa fgset gpapi stores steam epic-games-store ubisoft gog itchio ps4 ps5 xbox-one xbox-series-xs switch android ios vr battlenet origin drm-free xbox-360
oa fgset gpapi toggle
oa fgset showsettings

Expected settings

  • GamerPowerAPI: On
  • Channel: your chosen free games text channel
  • FreeStuffAPI: Off unless you enable it
  • Stores: selected PC, console, mobile, VR, and DRM-free sources

Old showsettings crash

Older versions could crash after stores were configured. The setup itself was valid, but oa fgset showsettings failed because a Python set was passed directly into cf.humanize_list().

Error in command 'freegamesset showsettings'
TypeError: 'set' object is not subscriptable

Root cause

conf.gamerpower.stores_to_check was stored as a set. Babel list formatting expects an indexable list-like object, so indexing a set caused the crash.

Upstream fix

The accepted fix converts the store set to a list before formatting it:

cf.humanize_list(list(conf.gamerpower.stores_to_check))

The same fix was also applied to freestuff.stores_to_check.

Note: the local workaround used sorted(...). Both list(...) and sorted(...) stop the crash. sorted(...) gives a stable alphabetical order, while list(...) is enough for the upstream fix.

Update your installed cog

Since the fix is now upstream, update and reload the cog:

oa repo update cray-bounty-cogs
oa cog update
oa reload freegames

Verify

oa fgset showsettings

If the update is successful, the settings embed should display normally instead of crashing.

Post-fix result

  • GamerPowerAPI: On
  • Channel: your chosen free games text channel
  • FreeStuffAPI: Off unless you enable it
  • Stores list: displays successfully

Notes

  • This is not an EmbedUtils issue.
  • This is not caused by missing Discord Embed Links permission.
  • GamerPowerAPI configuration can still be valid; the crash was limited to the settings display command.
  • Unrelated Birthday or YALC logs do not affect this issue.
