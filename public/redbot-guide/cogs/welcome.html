Welcome

Welcome and goodbye messages using Trusty welcome.

oa cog install trusty-cogs welcome
oa load welcome

Set channel + GIF

oa welcomeset greeting channel #welcome
oa welcomeset embed toggle
oa welcomeset embed image greeting GIF_URL

Final Remnant-style message

oa welcomeset greeting add 🩸 {0.mention}... another Traveler crosses into **{1.name}**. The Root stirs. The darkness remembers your name, **{0.name}**. You are soul number **{count}** to answer the call — whether you survive... is another matter entirely. *Welcome. If that word still means anything here.* 😶‍🌫️🔥
oa welcomeset greeting toggle
oa welcomeset greeting test

Variables

VariableMeaning
{0.mention}New member mention
{0.name}New member username
{1.name}Server name
{count}Member count/join count
