Welcome

Trusty Welcome setup for a public embedded welcome message with a dark Remnant 2 style.

Use this for a welcome-only channel. The message points new members to general chat, memes, and voice. Do not enable auto-delete if you want welcome messages to stay.

Install

oa cog install trusty-cogs welcome
oa load welcome

Channel placeholders

Replace these placeholders with your own Discord channel mentions or copied channel IDs.

PurposeExample placeholder
Welcome onlyWELCOME_CHANNEL_MENTION
Chilling/generalGENERAL_CHANNEL_MENTION
Post memesMEMES_CHANNEL_MENTION
Voice channelVOICE_CHANNEL_MENTION

Important: toggle commands flip the current state. Do not repeat toggle commands after they are already on, or you may turn them off.

Final safe commands

oa welcomeset greeting channel WELCOME_CHANNEL_MENTION
oa welcomeset whisper off
oa welcomeset greeting allowedmentions True users
oa welcomeset greeting allowedmentions False roles everyone

Clear old greeting formats

Before adding the final message, open the greeting list and delete old saved formats from the interactive menu.

oa welcomeset greeting list

Final Remnant-style welcome message

Replace the channel placeholders before sending.

oa welcomeset greeting add 🩸 **{0.mention}... another Traveler has crossed into {1.name}.**

The crystal hums. The realm has noticed you.

Before you wander deeper:

▸ For chilling, go to GENERAL_CHANNEL_MENTION
▸ For cursed relics and memes, post in MEMES_CHANNEL_MENTION
▸ For voice, join VOICE_CHANNEL_MENTION

Stay close to the signal, Traveler.
Some worlds welcome you. This one tests you.

**{count} survivor(s) answered the call today.**

Allowed mentions

CommandWhy it matters
oa welcomeset greeting allowedmentions True usersAllows {0.mention} to actually ping the new member.
oa welcomeset greeting allowedmentions False roles everyoneBlocks role pings, @everyone, and @here from the welcome system.

Commands to avoid

Because the welcome messages should not be deleted automatically, do not run these:

oa welcomeset greeting deleteprevious
oa welcomeset greeting deleteafter

Test and verify

oa welcomeset greeting test
oa welcomeset settings

Expected final state: greetings enabled, welcome channel set, previous greeting deleted false, delete after none, wait for verification true, whisper false, embeds true.

Optional bot welcome

Your bot welcome can stay default. If the bot subcommand supports msg or message, you can theme it too:

oa help welcomeset bot
oa welcomeset bot msg 🤖 **{0.name} has entered {1.name}.**

A machine soul has crossed the threshold.
Assign it purpose before the Root does.
