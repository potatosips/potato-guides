AutoReact

Auto-react to matched trigger text. Some unicode emojis may fail as invalid reaction emojis.

oa repo add seina-cogs https://github.com/japandotorg/Seina-Cogs
oa cog install seina-cogs autoreact
oa load autoreact

Usage

oa ar add <trigger> <emoji>
oa ar list
oa ar remove <trigger> <emoji>
oa ar reset <trigger>

If emoji fails

Try another native emoji or use a custom Discord emoji format: <:name:id>.
