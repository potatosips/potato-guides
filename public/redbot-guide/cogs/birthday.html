Birthday

Birthday announcements and birthday role.

oa repo add vex-cogs https://github.com/Vexed01/Vex-Cogs
oa cog install vex-cogs birthday
oa load birthday
oa bdset interactive
oa bdset channel BIRTHDAY_TEXT_CHANNEL_ID
oa bdset role BIRTHDAY_ROLE_ID

User birthday

oa bday set 04/04/2007

Admin force-set

Use a real member mention or selectable Discord user where @member is shown.

oa bdset forceset @member 9-24
oa bdset forceset @member 12-23
